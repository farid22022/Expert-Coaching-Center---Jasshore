# Campus image manifest

Original code-native SVG assets, generated by frontend/scripts/generate-campus-assets.cjs. Image generation tools were not available for this turn. Vector delivery avoids raster scaling/CLS and is smaller than AVIF/WebP variants for these procedural illustrations. No real people, stock photography or third-party logos. Every asset is below 6KB. Decorative imagery uses empty alt text; meaningful content keeps a textual title. User-provided photographs remain unchanged.
