# EXPERT COACHING CENTER — PUBLIC WEBSITE CLONE

## ROLE

You are a senior full-stack web developer and UI/UX engineer.

Your task is to **recreate the complete public-facing website of EXPERT COACHING CENTER**:

Reference website:

https://expertjashore.com/

The goal is to build a functional, responsive, production-quality clone of the **public website only**.

Do NOT implement or access the authenticated Admin Dashboard at this stage.

The final website should reproduce the reference site's:

* Admission functionality

while using a cleaner, modern, maintainable frontend architecture.
